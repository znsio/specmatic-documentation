# Configure GraphQL with SDL

Use `runOptions.graphqlsdl` to select a GraphQL mock listener or a running implementation for contract testing. These complete V3 examples require **Specmatic Enterprise** with GraphQL access. They use HTTP POST at `/graphql`.

## Save the contract and example

Follow the [Enterprise Docker setup](/references/configuration/local-openapi#docker-setup) and configure your [license](/enterprise_onboarding/license_key). Save all files in one folder and run commands there. Keep ports **9100**, **9101** and **9102** free; the optional demo needs Node.js 20+, and commands use a Bash-compatible shell.

Save this SDL as **catalog.graphqls**:

## Verified scope

These files and commands are shared with documentation checks against **Enterprise 1.28.3**: deterministic mocks, implementation tests, configured versus CLI endpoint selection, matching single-spec overrides, custom mock example directories, the test directory limitation and wrong-role validation. OSS 2.55.3 does not provide this GraphQL runtime; accepting a V3 GraphQL shape is not an edition-support promise.

TLS, multiple SDLs/listeners, remote sources, variables/aliases, generative cases, compatibility and example-validation commands need their own checks; this small recipe does not establish those behaviors.
