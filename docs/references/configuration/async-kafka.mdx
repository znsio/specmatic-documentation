# Mock Kafka with AsyncAPI

Start a local Kafka broker and a message mock from one V3 configuration. These examples were checked with **Enterprise 1.28.3**: an independent Kafka client sends a ping and checks the exact pong response.

## Save the inputs

Follow the [Docker setup](/references/configuration/local-openapi#docker-setup) and configure your [license](/enterprise_onboarding/license_key). Use a fresh directory and run the commands there. The client below needs **JDK 17+** and the downloaded Enterprise executable JAR. Set `SPECMATIC_ENTERPRISE_JAR` in the client terminal to that JAR's absolute path.

Ports **19092**, **19093**, **19095** and the mock control API port **19999** must be free. Stop each mock before starting the next variant. The embedded broker also opens dynamically assigned ports. Kafka listeners bind to **0.0.0.0** in this release, even though these examples advertise `localhost`; use a suitable local environment. Broker data is temporary and this setup is for local mocking.

Save `asyncapi.yaml`. It describes a service receiving `ping` and replying on `pong`. The payload constants make the generated response predictable without a separate example file.

<CodeBlock language="yaml" title="asyncapi.yaml">{require('./includes/async-kafka/asyncapi.yaml?raw').trimEnd()}</CodeBlock>
