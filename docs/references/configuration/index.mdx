## Understand the structure

| Section | What it does |
|---|---|
| `systemUnderTest` | Selects the service tested against a real implementation |
| `dependencies` | Selects the services to mock |
| `components` | Holds reusable sources, services, run options, data and settings |
| `specmatic` | Sets global behavior, governance and license configuration |
| `proxies` | Configures proxy targets and recording |
| `mcp` | Configures MCP server testing |

You can define services inline or reference components. A mock-only config needs no `systemUnderTest`; declaring a component alone does not select it for a run.

## Format version and product releases

These guides use configuration format **V3** (`version: 3`). That number is separate from the version of Specmatic you install. Protocols and commands have edition-specific availability; follow the linked protocol guidance before choosing a setup.

Using an older config? See [Upgrade Configuration](/references/configuration/upgrade-specmatic-config) and the [V2-to-V3 migration guide](/references/configuration/migrating-config-v2-to-v3). Legacy formats remain in those guides; use V3 for new configurations.

To browse a file you already have, use the [local configuration inspector](/references/configuration/inspect). It preserves your text and explains the limits of its browser checks.
